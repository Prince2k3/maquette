# README hero artwork

`maquette-hero.png` is a generated concept illustration for [[README]], inspired by the
Mount Rainier Hexagon preset in [[Demo/README]]. It depicts the library's solid terrain-chunk
concept, rather than an exact application render or a geological reconstruction.

The reference was captured from the visionOS simulator running that preset. Image generation
recomposed the mountain and cut walls on a charcoal studio background with brighter lighting,
without simulator controls or window chrome. The README labels the result as an illustration.

The `assets/` directory contains documentation artwork only. These files are not added to the
Swift package target or its runtime resources.
